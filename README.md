# ElderCare

A simple website for a fictional senior centre, built to practice front-end development and version control fundamentals.

## Pages
- Home (`index.html`)
- About (`About.html`)
- Services (`Services.html`)
- Community Outreach (`Events.html`)
- Contacts (`Contacts.html`)

## Project structure

```
ElderCare/
├── css/       stylesheets, one per page
├── images/    logo and photos
└── *.html     the five pages
```

## Tech
- HTML, CSS (no frameworks)

## Status
Structure reorganised and published through pull requests. Next step is deploying the site online with GitHub Pages.
